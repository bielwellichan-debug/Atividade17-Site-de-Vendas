# Atividade 17 - Site de vendas 💰
Nesta atividade fomos instruidos pelo nosso professor Vedilson a criarmos um site para vender produtos, onde cada aluno deveria montar um site de um tema específico que foi sorteado a ele.

## Qual foi o meu tema? 🤔
Meu tema foi uma loja que vende meias avulsas para recompor pares perdidos, e o nome que decidi dar para a empresa foi "Meias Fantasmas" inspirado em "Os caça-fantasmas"!

## O que tivemos que usar? 💭
Fomos instruídos a utilizar HTML5, CSS3, Bootstrap e fazer um site com responsividade!
